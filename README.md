# Go Error Handling Basics

This Go example demonstrates fundamental error handling principles. It showcases functions returning multiple values (result, error), checking for `nil` errors, creating custom error variables, and propagating errors with added context using `fmt.Errorf` and `%w`. The example also illustrates how to check for specific error types within an error chain using `errors.Is`.

## Language

`go`

## How to Run

1. Save the code as `main.go`.
2. Open a terminal in the same directory.
3. Run the program using: `go run main.go`
